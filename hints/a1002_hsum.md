hsum4: после `movhlps`+`addps` нужную сумму дают элементы 0 и 1; скопируйте регистр, `shufps xmm1, xmm1, 1` переносит элемент 1 в позицию 0, затем `addss`.
Основной цикл: условие «i + 4 <= n» удобно записать как `i < n - 3` (`lea rcx, [rsi - 3]`; сравнение знаковое — n может быть 0).
После цикла сделайте горизонтальную сумму, а потом скалярный хвост: `addss xmm0, [rdi + rax*4]` (скалярный операнд выравнивания не требует).
