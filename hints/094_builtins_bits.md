Имя функции, из которой вызван макрос, даёт встроенная константа `$$FUNC` (напечатайте её через `%s`).
Степень двойки: ровно один единичный бит, т.е. `x != 0 && (x & (x - 1)) == 0`.
`log2_floor`: у uint 32 бита, старший единичный бит стоит на позиции `31 - x.clz()`.
`next_pow2`: для x > 1 ответ `1u << (32 - (x - 1).clz())`; x <= 1 разберите отдельно.
Остальное — `bswap(x)`, `(a ^ b).popcount()`, `x.ctz()`.
