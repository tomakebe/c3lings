Same skeleton as saxpy, but with two accumulators: `vfmadd231ps ymm0, ymm2, [rsi + rax*4]` and the same for `+32` with ymm1.
Conditions: main loop while rax < n - 15, then one step of 8 if rax < n - 7.
Reduction: `vaddps ymm0, ymm0, ymm1`, `vextractf128 xmm2, ymm0, 1`, `vaddps xmm0, xmm0, xmm2`, then `vmovhlps`/`vaddps`/`vshufps ..., 1`/`vaddss`.
Tail: `vmovss` + `vfmadd231ss`. Don't forget `vzeroupper`.
