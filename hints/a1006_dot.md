Каркас как в saxpy, но аккумуляторов два: `vfmadd231ps ymm0, ymm2, [rsi + rax*4]` и то же для `+32` с ymm1.
Условия: основной цикл пока rax < n - 15, затем один шаг по 8, если rax < n - 7.
Свёртка: `vaddps ymm0, ymm0, ymm1`, `vextractf128 xmm2, ymm0, 1`, `vaddps xmm0, xmm0, xmm2`, затем `vmovhlps`/`vaddps`/`vshufps ..., 1`/`vaddss`.
Хвост: `vmovss` + `vfmadd231ss`. Не забудьте `vzeroupper`.
