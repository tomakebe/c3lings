`push`: `sz i = self.len++;` и затем `self.x[i] = p.x;` и т.д. для каждого массива.
`get`: верните литерал структуры `{ .x = self.x[i], ... }` — имя можно не заполнять.
`integrate`: обычный `for` по `0..len`; порядок операций такой же, как в `aos_integrate`
(сначала `vy`, потом `x`, потом `y`), иначе float'ы не совпадут побитово.
`swap_remove`: скопируйте элемент `len - 1` на место `i` во ВСЕХ семи массивах, затем `len--`.
`tick_life`: цикл `while (i < self.len)`; после удаления `i` не увеличивайте.
