atomic_cas: the expected value goes in rax (`mov rax, rsi`), then `lock cmpxchg qword ptr [rdi], rdx`, `sete al`, `movzx eax, al`.
atomic_max: read *p into rax; in a loop: if rax >= v — exit (rax is exactly the old value); otherwise `lock cmpxchg [rdi], rsi`; on failure (`jne`), rax already holds the fresh value — repeat the comparison.
