Получив `Time? t = file::last_modified(e.path);`, сначала обработайте ошибку: `if (catch t) { ...; continue; }` — после этого `t` распаковано (flow typing) и его можно сравнивать с `e.mtime`.
Присвойте `e.mtime = t;` ДО вызова reload: тогда и битый файл не будет перечитываться каждый опрос, а `reload` скопирует новое mtime вместе с остальной записью.
`if (catch self.reload(i)) { /* ERROR ... */ continue; }`, затем `e.version++; changed[i] = true; reloads++;` и лог.
Перелинковка — отдельным циклом ПОСЛЕ первого: иначе материал, стоящий до шейдера, не увидит его новую версию.
