Чтобы менять переменные вызывающего, параметры должны быть выражениями: `#a`, `#b`, а внутри — `#a = #b;`.
Макрос с `#`-параметрами обязан называться с `@`: `macro void @swap(#a, #b)`, вызовы — `@swap(x, y)`.
То же для `@or_else(value, #fallback)`: `#fallback` вычисляется, только когда до него доходит выполнение.
Текст выражения даёт `$stringify(#cond)`.
