`set`: первой строкой — `if (x < 0 || y < 0 || x >= W || y >= H) return;`, затем запись
и `self.plotted++`.

`line`: аккуратно перенесите псевдокод Zingl из шапки. Обратите внимание, что `dy`
хранится ОТРИЦАТЕЛЬНЫМ (`-|y1 - y0|`) — от этого оба условия `e2 >= dy` и `e2 <= dx`
работают сразу для всех октантов. Цикл `while (true)` с `break`, когда дошли до конца.
