`quantize_depth`: сначала обработайте края (`d <= near` -> 0, `d >= far` -> `DEPTH_MAX`),
потом `t = (d - near) / (far - near)` и `(uint)(t * (float)DEPTH_MAX)`.

`make_key`: поле `translucent` у вас уже заполнено, осталось развести две ветки.
Для полупрозрачных `k.material = 0`, а глубину переворачивают: `DEPTH_MAX - q`,
чтобы дальние объекты получили меньший ключ и рисовались первыми.
