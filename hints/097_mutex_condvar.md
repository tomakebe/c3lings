Счётчик: оберните `c.value++;` в `c.mu.@in_lock() { ... };` (или lock() + defer unlock()).
Ждать в pop нужно, пока элементов нет И очередь ещё не закрыта: `self.count == 0 && !self.closed`.
После добавления элемента условие «очередь непуста» стало истинным — сообщите об этом через `self.not_empty.signal();`.
Без signal потребители проспят вечно, и раннер оборвёт программу по таймауту.
