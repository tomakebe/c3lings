Слот занят, если `used == true`. `connect` — линейный поиск первого свободного
слота: записать в него `{ cb, ctx, true }` и вернуть индекс.
`disconnect` — проверить, что `0 <= id < MAX_SLOTS`, и обнулить слот (`= {}`).
`emit` — `foreach (&s : self.slots) if (s.used) s.cb(s.ctx, amount);`
Обработчик сам приводит `void* ctx` к своему типу — сигналу это знать не нужно.
