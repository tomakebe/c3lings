`file::open` возвращает `File?` — пробросьте ошибку наверх оператором `!`.
Сразу после открытия добавьте `defer (void)f.close();` (посмотрите, как сделано в `total_from_file`).
Без close данные остаются в буфере, и чтение видит пустой файл.
Отсутствующий файл: вместо `!!` используйте `if (catch err = total_from_file(...)) { ... }`.
