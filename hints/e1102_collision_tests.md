Векторы `Vec2 = float[<2>]` умеют `a.dot(b)`, `a - b`, `v / s`, доступ `v.x` и `v[i]`.
Круг–круг: `d = b.c - a.c`, пересечение при `d.dot(d) <= (ra+rb)²`; нормаль `d / |d|`, глубина `ra + rb - |d|`.
Круг–коробка: `p = clamp(c, min, max)` покомпонентно (`math::clamp`). Если `p != c` — работаем
с вектором `c - p`; если центр внутри — сравните четыре расстояния до граней и выберите наименьшее.
Луч: `inv = 1.0f / dir[i]`, `t1 = (min[i] - o[i]) * inv`, `t2 = (max[i] - o[i]) * inv`, при `t1 > t2` поменяйте местами;
`tmin = max(tmin, t1)`, `tmax = min(tmax, t2)`, промах при `tmin > tmax`.
