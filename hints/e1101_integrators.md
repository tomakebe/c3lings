Каждая функция возвращает новое `State { x, v }`; производная состояния — это `(v, accel(x))`.
Явный Эйлер: `{ s.x + s.v * dt, s.v + accel(s.x) * dt }`. Полунеявный отличается лишь тем,
что положение двигается уже НОВОЙ скоростью.
Верле: посчитайте `a = accel(s.x)`, новое `x`, затем `v' = v + (a + accel(x'))/2 * dt`.
RK4: для каждой из четырёх оценок нужны две производные — `kNx` (это скорость) и `kNv`
(это ускорение). `k2x = s.v + k1v*dt/2`, `k2v = accel(s.x + k1x*dt/2)` и так далее;
итог `s + (k1 + 2*k2 + 2*k3 + k4) * dt/6` для каждой компоненты.
