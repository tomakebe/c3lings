`@cname("...")` принимает строку — настоящее имя символа в C-библиотеке.
Прототип qsort переводится почти дословно: `extern fn void qsort(void* base, usz count, usz size, CompareFn cmp);`
(`size_t` -> `usz`, указатель на функцию -> alias `CompareFn`, `const` просто исчезает).
В компараторе сначала сравните score (больший — раньше, т.е. вернуть -1), затем id (меньший — раньше).
