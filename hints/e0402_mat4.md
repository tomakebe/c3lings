`mul_vec`: `m.cols[0] * v.x + m.cols[1] * v.y + m.cols[2] * v.z + m.cols[3] * v.w`.
`mul`: `for j in 0..3: r.cols[j] = mul_vec(a, b.cols[j])`.
`transpose`: `r.cols[i][j] = m.cols[j][i]` (элемент вектора берётся индексом).
`translation`: единичная матрица и `cols[3] = { t.x, t.y, t.z, 1 }`; `scaling` — диагональ.
`transform_point`: `mul_vec(m, { p.x, p.y, p.z, 1 }).xyz`; для направления `w = 0`.
