Мёртвые зоны: работайте с модулем значения (`int a = raw < 0 ? -raw : raw;` — в `int` значение
-32768 помещается), затем перемасштабируйте `(a - dz) * 1000 / (32767 - dz)`, ограничьте 1000 и
верните знак. Для радиальной зоны считайте в `long` (x*x + y*y не влезет в int) и используйте `isqrt`.
В C3 смешивание `long` и `int` в выражении иногда требует явного `(long)`.
`apply`: `if (try c = key_from_scancode(e.code)) { ... } else { self.unmapped++; }`.
Для оси стика сначала сохраните сырое значение, затем пересчитайте ОБЕ компоненты через
`radial_deadzone(self.raw_lx, self.raw_ly, STICK_DZ, &self.stick_x, &self.stick_y)`.
`move_x`: клавиатура даёт -1000/0/1000; сравните модули и верните больший.
