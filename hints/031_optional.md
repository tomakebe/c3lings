Четыре правки, все про Optional:
1. Новая ошибка объявляется на верхнем уровне: `excuse ИМЯ;`.
2. Функция, которая может вернуть ошибку, должна иметь тип результата `int?`, а не `int`.
3. `NOT_A_DIGIT` без суффикса — это просто значение типа `fault`. Пустой Optional получается с `~`.
4. Переменная, в которую кладут Optional, тоже должна быть Optional: `int? bad = ...`.
