# c3lings

Курс в стиле [ziglings](https://codeberg.org/ziglings/exercises) и [rustlings](https://rustlings.rust-lang.org/):
сотни маленьких сломанных программ, которые нужно починить. Курс ведёт от «Hello, world» на
[C3](https://c3-lang.org) до уровня, на котором вы сами пишете игровые движки.

Три трека проходятся подряд:

1. **Язык C3** (`exercises/`, 125 упражнений): от основ до generics, макросов, рефлексии,
   аллокаторов, многопоточности и expert-тем: виртуальные машины, lock-free, сериализация.
2. **Ассемблер x86-64** (`asm/`): регистры, ABI, стек, SIMD/AVX2, системные вызовы, атомики,
   производительность и в финале JIT-компилятор.
3. **Архитектура игровых движков** (`engine/`): игровой цикл, память, ECS, рендеринг, физика,
   job system, ресурсы, скриптинг, сеть, инструменты и итоговый мини-движок.

Полная программа — в [CURRICULUM.md](CURRICULUM.md).

## Установка

Курс рассчитан на **c3c 0.8.5**. Язык быстро меняется, а в репозиториях дистрибутивов часто лежит
старая версия (в Arch `extra` — 0.7.x), поэтому проще всего поставить компилятор прямо в проект:

```sh
./tools/get-c3c.sh        # скачает c3c 0.8.5 в ./.c3c — раннер найдёт его сам
```

Ещё нужен системный C-компилятор (`gcc` или `clang`): C3 использует его для линковки, а трек по
ассемблеру — для сборки `.s`-файлов.

Если хотите пользоваться своим c3c, укажите его так: `C3C=/path/to/c3c ./c3lings`.

## Как проходить

```sh
./c3lings            # проверить всё по порядку и показать первое нерешённое упражнение
./c3lings watch      # то же, но с автоматической перепроверкой при сохранении (лучше всего с inotify-tools)
./c3lings hint 042   # подсказка
./c3lings run 042    # собрать и запустить одно упражнение
./c3lings list       # список упражнений и статус
```

Порядок работы:

1. Запустите `./c3lings watch` в одном терминале.
2. Откройте файл, который он укажет. **Шапка-комментарий — это учебник**: прочитайте её целиком.
3. Почините программу так, чтобы она скомпилировалась и напечатала ожидаемое.
4. Сохраните файл: раннер перейдёт к следующему упражнению.

В треках по ассемблеру и движкам каждая глава начинается с теории в `asm/docs/` и `engine/docs/`.
Прочитайте главу **до** упражнений.

Эталонные решения лежат в `solutions/`. Подглядывайте только после того, как решили сами
(или если застряли надолго): полезно сравнить свой вариант с эталоном.

Чтобы начать упражнение заново, удобно держать курс в git: `git checkout -- exercises/042_*`.

## Полезное

* Справочник по языку для вашей версии компилятора: `.c3c/c3/MANUAL.md`
* Исходники стандартной библиотеки: `.c3c/c3/lib/std/` (лучший учебник идиоматичного C3)
* Сайт языка: https://c3-lang.org, Discord сообщества: ссылка на сайте

## Структура

```
c3lings              раннер
exercises/           трек 1: язык
asm/docs, asm/exercises         трек 2: ассемблер
engine/docs, engine/exercises   трек 3: движки
solutions/           эталонные решения
checks/              ожидаемый вывод (не редактировать)
hints/               подсказки
tools/get-c3c.sh     установка компилятора
AUTHORING.md         для авторов упражнений
```
